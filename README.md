# نظام منيو المطعم بالـ QR — دليل الاستخدام

نظام كامل: العميل يمسح QR على الترابيزة، يشوف المينو، يطلب، الطلب يوصل المطبخ برقم، وممكن يدفع من موبايله.

## 📁 هيكل المشروع
```
restaurant-app/
├── backend/          # السيرفر + قاعدة البيانات + الدفع
│   ├── server.js
│   ├── db.js
│   ├── routes/
│   │   ├── menu.js
│   │   ├── orders.js
│   │   ├── payment.js       (Paymob)
│   │   └── features.js      (زرار الخدمة + قائمة الانتظار)
│   ├── data/seed.js         # بيانات المينو التجريبية
│   ├── generateQR.js        # توليد QR لكل ترابيزة
│   └── .env.example
├── frontend/
│   ├── menu.html      # صفحة العميل (تفتح من الـ QR)
│   ├── kitchen.html   # شاشة المطبخ
│   ├── waiter.html    # شاشة الويتر (زرار الخدمة + قائمة الانتظار)
│   ├── reception.html # شاشة الاستقبال (تسجيل قائمة الانتظار)
│   ├── app.js
│   └── style.css
└── qrcodes/           # هنا هتتحط صور QR بعد التوليد
```

## 🚀 التشغيل محليًا

### 1) الباك اند
```bash
cd backend
npm install
cp .env.example .env      # واملى بيانات Paymob لو هتفعّل الدفع الأونلاين
npm run seed               # يضيف مينو تجريبي — عدّل data/seed.js ببيانات مطعمك
npm start
```
السيرفر هيشتغل على `http://localhost:3000`

### 2) الفرونت اند
افتح `frontend/menu.html` بأي سيرفر ستاتيك بسيط (مش بمجرد فتح الملف مباشرة عشان الـ fetch يشتغل صح)، مثال:
```bash
cd frontend
npx serve .
```
أو أي إضافة "Live Server" في VS Code.

### 3) رابط المنيو التجريبي
```
http://localhost:5500/menu.html?table=5
```

### 4) توليد QR لكل الترابيزات
```bash
cd backend
MENU_URL=https://your-real-domain.com/menu.html node generateQR.js
```
هيطلعلك صور PNG في مجلد `qrcodes/` — كل صورة لترابيزة، اطبعها وحطها فوق كل ترابيزة.

⚠️ **مهم:** لما ترفع المشروع على دومين حقيقي، لازم تغيّر `API` في أول ملف `frontend/app.js`, `kitchen.html`, `waiter.html`, `reception.html` من `http://localhost:3000/api` لدومين السيرفر بتاعك.

## ✅ المزايا المتوفرة كاملة وجاهزة للاستخدام فورًا

| الميزة | فين تلاقيها |
|---|---|
| مينو رقمي + طلب من الموبايل | menu.html |
| رقم طلب يوصل المطبخ لحظيًا | kitchen.html |
| دفع أونلاين (فيزا/محافظ/فوري عبر Paymob) أو دفع بالكاشير | app.js + payment.js |
| 🔔 زرار الخدمة (الشيك / مية / أدوات) | menu.html (تحت يمين الشاشة) + waiter.html |
| ⭐ تقييم لحظي بالإيموجي + تنبيه فوري لو العميل مش راضي | يظهر تلقائيًا لما الطلب يبقى "جاهز" |
| 💰 تسعير ديناميكي (Happy Hours / خصم آخر اليوم) | من جدول المينو: `happy_hour_price`, `happy_hour_start`, `happy_hour_end` |
| 👥 الطلب الجماعي وتقسيم الفاتورة | زرار "اطلب مع صحابك" في أعلى المينو |
| 📋 قائمة انتظار + طلب مسبق وهو واقف | reception.html + waiter.html |
| 📲 مشاركة المينو / الطلب الجماعي على واتساب | زرار مدمج (wa.me link) |

## ⚙️ مزايا جاهز لها الكود لكن محتاجة منك حاجة إضافية

- **🎥 منيو الفيديو**: الكود جاهز يعرض فيديو 3 ثواني لأي صنف — بس محتاج تصوّر فيديوهات الأطباق وترفعها على أي استضافة (حتى يوتيوب/درايف) وتحط اللينك في عمود `video_url` بجدول `menu_items`.
- **🕶️ الواقع المعزز (AR)**: الكود بيدعم عرض موديل 3D لو حطيت لينك ملف `.glb` في عمود `model_url`. عمل الموديلات دي بيحتاج مصور/استوديو 3D متخصص — مش حاجة بتتكتب كود، دي أصول (assets) لازم تتجهز بره.
- **📱 بوت واتساب كامل (يرد ويحفظ تفضيلات)**: اللي عملته دلوقتي هو لينك واتساب بيفتح المنيو مباشرة (شغال فورًا). أما "بوت" فعلي بيرد تلقائي ويحفظ بيانات العميل فمحتاج حساب WhatsApp Business API (زي Twilio أو 360dialog) وده بيتكلف اشتراك شهري ومراجعة من ميتا — قولّي لو عايز أظبط التكامل بمجرد ما يبقى عندك حساب.
- **📍 الطلب أثناء الطريق (Geofencing)**: تتبع الموقع المستمر محتاج تطبيق موبايل حقيقي (الموبايل بيوقف التتبع لو المتصفح اتقفل)، مش صفحة ويب عادية. لو حابب نعمل نسخة مبسطة (تتبع وقت ما الصفحة مفتوحة بس) قولّي أظبطهالك.

## 💳 تفعيل الدفع الإلكتروني (Paymob)
1. اعمل حساب على [accept.paymob.com](https://accept.paymob.com)
2. هتلاقي في لوحة التحكم: `API Key`, `Integration ID`, `Iframe ID`
3. حطهم في `backend/.env`
4. من إعدادات الحساب في Paymob، حط رابط الـ Webhook بتاعك: `https://your-domain.com/api/payment/webhook`

Paymob بتغطي فيزا/ماستركارد ومعظم المحافظ الإلكترونية وكود الدفع من فوري بنفس التكامل.

## 🗄️ قاعدة البيانات
SQLite (ملف واحد `restaurant.db` بيتعمل تلقائي أول ما تشغّل السيرفر) — مناسبة لمطعم واحد أو فرعين. لو المشروع كبر (فروع كتير، تقارير ثقيلة) سهل ننقلها لـ PostgreSQL لاحقًا.
